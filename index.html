How to use it

Download

Download and extract the Python app package on Windows.

02

Use the Store tab to browse and download, then set the 7-Zip path in Settings. You can also add a local game folder or executable and fetch cover art.

Set up 7-Zip, add local games, choose a theme, and launch supported games from your library.

The app combines a built-in SteamRIP browser, download handling, 7-Zip extraction, and a library for games already on your PC. Set your 7-Zip executable path in Settings before extracting archives.
